# Preserve donor stock inputs and reference performance ceilings

The accepted thirty-car roster keeps its donor identities, geometry, drivetrain
and verified stock inputs. Apply the recovered Juiced 2 package, class and entry
equations consistently to those adapted inputs. Retain the matched original
CarModInfo row and its provenance separately; it is not an exact donor tune.

Preserve the reference counterpart's maximum power-to-mass ratio when adapting
tuning endpoints. Keep its proportional mass reduction against the donor's stock
mass, then derive maximum power from that adapted minimum mass and the reference
maximum ratio. Use the actual float32 results in the original class calculations.
Record the resulting endpoints, maximum class and source counterpart for every car.
Incorrect stock data, including the inherited 320 kg Evo value, requires a primary
specification correction before publication.

The rejected percentage-power-gain adaptation left all three available muscle
cars below mandatory late-career muscle events. Preserving the source performance
ceiling retains the original progression capability without changing donor stock
power or weakening entry rules. This is an explicit smaller-roster adaptation
under [ADR-0003](0003-start-with-thirty-vehicles.md), not a recovered original
thirty-car tuning table. Do not increase a car's ceiling simply to make a prototype
available; use the source counterpart's limit and audit event reachability.

New profiles receive the first available car in the accepted roster that satisfies
the recovered Rookie entry rules. Existing owned vehicles are preserved. Verify
all thirty adapted ranges and all career/sponsor event class requirements before
publishing the new content or claiming a complete legal career path.
