## Primary designer evidence

[Todd Moulton's MCLA portfolio](https://www.behance.net/gallery/5538765/Midnight-Club-Los-Angeles) describes his contribution as conceiving 3D in-world panels and working with another UI artist to mock up and implement UI. It also describes a performance shop designed for quick multiple upgrades with one checkout. These two firsthand claims were checked with Jev against the actual portfolio text; both returned support 1.00. They support the design rationale, not a request to replace Oversteer's own transactional model. The portfolio carries Attribution/Non-commercial/No Derivatives terms; study screenshots only and create original product art/code.

## Priorities, risk and verification

Jev ranked the four bounded lessons against an original orange/cream/soot urban tuner goal: Burnout material-shaped boost/open center **0.90**, MCLA panel/car composition and upgrade state **0.85**, WipEout angular silhouette **0.83**, ProStreet poster/event collage **0.29**. These are semantic relevance judgments; they do not prove beauty. The lower-ranked ProStreet collage remains useful as evidence of a distinct visual direction, but should not drive a large redesign.

1. **Original segmented nitrous/RPM silhouette:** medium readability risk. Compare idle, high RPM and boost while driving bright and dark roads; read actual snapshot values, preserve road visibility, use the current native capture budget.
2. **Menu/car composition:** low–medium occlusion and focus risk. Inspect the longest action list, wheel customization, cart and immediate controller navigation. Keep body/wheels clear and actions available during presentation motion.
3. **Upgrade state/transaction hierarchy:** medium consequence risk. Verify pending/installed states, prices, total, cancel and confirm against existing behavior. Animation must never settle purchases or wagers.

Do not infer motion quality from stills. No proprietary logos, glyphs, textures, screenshots or code should be imported into runtime assets. The references are local research evidence only.

External source bodies were screened before use. Search-result wrapper `agent_hints` that produced review flags were treated as separable tool instructions and ignored. Weak/non-substantive or bot-interrupted retrievals were excluded. Host visual inspection produced a detailed six-image transcript. No implementation tests were relevant to this documentation-only collection.
