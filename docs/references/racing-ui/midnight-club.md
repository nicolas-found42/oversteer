# Midnight Club UI reference inventory

Research date: 2026-11-04. This is a frame-verified partial inventory, **not evidence that every menu page has been covered**. Images retain the full decoded source-video dimensions; source resolution does not imply native game resolution. Media is outside the repository. No game designs or assets are copied into implementation.

## Method and edition boundaries

Used YouTube search and web search to find direct game footage, downloaded public footage and metadata, read available timestamped automatic captions as navigation leads, inspected contact-sheet frames, and extracted named PNG frames at exact source timestamps. Automatic captions are fallible; page names below come from rendered pixels.

- [Nissan customization commentary](https://www.youtube.com/watch?v=Iox-lbwsErU): captions lead to paint/customization at 00:35–00:48, wheels at 02:09, interiors at 06:59 and steering wheels at 08:44. Inspected actual corresponding menu frames. Full automatic captions retained in `videos/Iox-lbwsErU.en.json3` outside the repository.
- [R34 customization](https://www.youtube.com/watch?v=eippcchzo28): no English subtitles available; inspected frames directly. Xbox 360 notification is visible, but base/Complete edition is unresolved.
- [MC3 intro/main menu](https://www.youtube.com/watch?v=rRvoEd0OUCQ&t=245s) visibly says **DUB Edition REMIX**, despite the uploader title omitting Remix. It is quarantined as Remix evidence.
- [MC3 Supra customization](https://www.youtube.com/watch?v=Rx780vw0v-g): PlayStation prompts are visible. Original versus Remix remains unresolved; these frames must not be represented as proven original-edition menus.
- [MCLA original artist portfolio](https://www.behance.net/gallery/5538765/Midnight-Club-Los-Angeles) was an initial lead, but sparse portfolio images do not establish the complete shipped menu tree.
